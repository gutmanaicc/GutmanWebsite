## מצב preview

- מקור `index.html` כולל `noindex, nofollow` לפני JavaScript. כל התוכן המובנה הישן הוסר: חמישה קורסים, עומס לימוד של 20 שעות, מיקום כאילו אושר וטענת ״הראשונה בישראל״.
- מקור `public/robots.txt` חוסם את כל הסריקה. אין היתר נפרד לזחלני AI שעוקף את החסימה.
- `useSeo` משאיר noindex בכל preview ובכל סביבת פיתוח, מסיר canonical ואינו מזריק JSON-LD. אין canonical שמצביע לכתובת preview.
- אינדוקס בדפדפן דורש build production, ערך מפורש `VITE_ACADEMY_PRODUCTION_APPROVED=1`, origin מדויק `https://gutmanai.com` וכתובת מתוך רשימת העמודים הציבוריים. עמודי ארכיון מסמנים גם `noindex: true`.
- `scripts/academy-seo-build.mjs` דורש בנוסף `VERCEL_ENV=production` כדי לייצר HTML ו-robots שמאפשרים סריקה. כך גם build ב-Vercel Preview עם דגל אישור אינו הופך לאתר מאונדקס. משתנה אישור זה הוא מתג הפצה, לא מנגנון אבטחת משתמשים או אישור מועד.

## sitemap ותוכן למנועים

`sitemap.xml` מכיל תשע כתובות ייצור ייחודיות: בית, קטלוג, שלושת הסמינרים וארבעת העמודים המוסדיים. אין מועדים, lastmod לא מאומת, עמודי ארכיון, ניהול או רכישה. `llms.txt` מתאר את שלושת הסמינרים בזהירות, מציין את מצב התצוגה המקדימה ואינו מסיק זמינות או תשלום מביקור בעמוד. יש לעדכן את תיאור מצב הפרסום בו כחלק משחרור מאושר.

`orgSchema`, `courseSchema` ו-`faqSchema` יכולים להופיע רק בעמוד ציבורי שאינדוקסו אושר. אין Offer, CourseInstance, ספירת נרשמים, דירוג, Accreditation או תאריך בתוך הסכמות. FAQ חייב להתאים לתוכן הגלוי.

## פרסום לאחר אישור מפורש בלבד

1. להשלים תחילה את חסמי השחרור והתוכן במסמך release; אישור פרסום האתר ואישור מועדי הרשמה הם החלטות נפרדות.
2. להגדיר `VITE_ACADEMY_PRODUCTION_APPROVED=1` בסביבת Production בלבד. להותיר Preview/Development בערך `0` או ללא ערך. אין לשנות את קבצי המקור ל-index ידנית.
3. לוודא שתהליך Vercel מאושר מוסר `VERCEL_ENV=production` לבנייה ושתוסף `academySeoBuild()` נמצא במערך plugins. מחוץ ל-Vercel הבנייה נשארת חסומה בכוונה; יש להתאים את אימות יעד ההפצה לפני מעבר אירוח.
4. לוודא שכותרות `X-Robots-Tag: noindex, nofollow` מכסות את הנתיבים הפרטיים ואת הארכיון, גם עבור זחלנים שאינם מריצים JavaScript. אין לחסום את הארכיון ב-robots של הייצור: הזחלן צריך לקרוא את הוראת noindex כדי להסיר כתובת שאונדקסה בעבר.
5. לבדוק את HTML הבנוי, robots, sitemap, headers ו-canonical בדומיין הייצור, ואת noindex ב-preview. רק לאחר אישור הפצה ובדיקות יש להגיש את sitemap ב-Search Console ולנטר שגיאות crawl.

## מגבלות ידועות

האתר הוא SPA ללא prerender. בגרסה זו כותרות ותיאורים לכל נתיב נכתבים בצד לקוח; זחלן שיתוף שאינו מריץ JavaScript עדיין יקבל את תגיות הבית הכלליות. סריקת noindex של preview אינה תלויה ב-JavaScript. לפני השקעה בקידום נרחב מומלץ להוסיף HTML נפרד/prerender לנתיבי התוכן, לאחר בחירת תשתית אירוח וגיבוי לנתונים הדינמיים. לא נטענו בדיקה ב-Search Console, מעבר backlink, ציון SEO או שיפור דירוג שלא נמדדו.

## בדיקות שבוצעו

בדיקת Node של תוסף הבנייה בדקה: ברירת מחדל, Preview עם דגל 1, שרת פיתוח עם דגל 1, ייצור ללא אישור, וייצור מאושר. בכל המקרים התקבלו הוראות metadata/robots הצפויות; סגירת שרת פיתוח אינה כותבת robots. בדיקת Python קראה את ה-XML, אימתה תשע כתובות ייחודיות, היעדר מועדים ועמודים ישנים, והיעדר JSON-LD ישן ב-index. עמוד payment-thanks ההיסטורי אינו טוען עוד שתשלום התקבל או מקום נשמר. בדיקות דפדפן ובנייה מלאה מתועדות בנפרד במסמך השחרור.
