# רשימת בדיקות ושחרור — אקדמיית גוטמן 2.0

תאריך: 12.10.2026. יעד נוכחי: תצוגה מקדימה לעיון הבעלים. אין אישור לפרסום לייצור, לגביית לקוחות או להפעלת מועדים בטיוטה.

## בוצע ואומת במסגרת בדיקת SEO

| בדיקה | תוצאה | מה נבדק בפועל |
| --- | --- | --- |
| מנגנון HTML/robots בבנייה | עבר | Node הפעיל את תוסף הבנייה בחמישה מצבים: ברירת מחדל, preview עם אישור, פיתוח עם אישור, ייצור ללא אישור וייצור עם אישור; כתיבה הייתה לספריות זמניות בלבד |
| מצב preview במקור HTML | עבר | meta noindex קיים לפני JavaScript; אין JSON-LD ישן ב-index |
| sitemap | עבר | XML תקין, תשע כתובות ייחודיות בדומיין הקיים בלבד, שלושה סמינרים ומידע מוסדי, ללא ארכיון או תאריך לא מאושר |
| עמוד תודה היסטורי | עבר בבדיקת מקור | הוסרו טענות ״התשלום התקבל״, ״המקום שלכם שמור״ והבטחת מסמך אוטומטי; נכתב שהעמוד אינו מאמת עסקה |
| מחקר Morning/Grow | קריאה בלבד | נקראו מסמכי הספק הרשמיים; לא נוצרו עסקאות, חיובים או קריאות webhook לספק |

בדיקות אלה אינן טענה שסליקה, פרסום או הדפדפן עברו בדיקה מקצה לקצה.

## מצב בדיקות הגרסה המשולבת

- [x] TypeScript ובניית Vite מלאה, עם תיעוד הפקודה והפלט בפועל.
- [x] בדיקות שרת למחיר 1,190 ₪, מחיר מתוכנן 1,490 ₪, אי-הוספת מע״מ, קופונים, מושבים, אישור מועדים, webhook כפול, תשלום שנכשל ופקיעת שמירת מקום.
- [x] בדיקת דפדפן לבית, קטלוג, שלושת הסמינרים, ארכיון, תשלום חסום, ניהול וסטטוס הזמנה.
- [x] desktop/tablet/mobile כולל RTL, מקלדת, focus, טופס שגיאות, ניווט ומניעת גלילה אופקית.
- [x] פתיחה ישירה של נתיבי ארכיון ושל payment-thanks; אין טופס ליד ישן, מחיר לרכישה או אישור תשלום על סמך redirect.
- [ ] בדיקת noindex ב-DOM וב-HTML של preview וכותרות HTTP במסלול האירוח שנבחר; בדיקת canonical רק בייצור מאושר.
- [x] מדידת ביצועים ונגישות בפועל; תוצאות Lighthouse מקומיות מפורטות להלן. Core Web Vitals בייצור עדיין לא נמדדו.
- [x] סריקת קישורים פעילים והפרדה ברורה בין תוצרי עבר, הדגמות ועדויות על הסמינרים החדשים.

## חסמים לפני גבייה ופרסום

- [ ] אישור מפורש של הבעלים לפרסום הגרסה; אין להסיק אישור מהשלמת בדיקות.
- [ ] אישור כל מועד בנפרד: מקור, יום בשבוע, 15:00–20:00, מנחה, מיקום/כתובת מאומתת, זמינות מקום, חגים והיעדר התנגשות עם התחייבויות ללקוחות קיימים.
- [ ] בדיקה אנושית של יתרת התחייבויות במסלולי אופנה/סטודנטים/מטפלים. לא הייתה כאן גישה לרשומות לקוחות או תשלומים.
- [ ] בסיס נתונים מתמשך ומנגנון טרנזקציות המתאים לאירוח; אין להפעיל SQLite מקומי כמסד נתונים מתמשך בפונקציות Vercel.
- [ ] אימות והרשאות ניהול לייצור, סודות בצד שרת וגיבוי/שחזור. לא להעתיק סודות למשתני VITE.
- [ ] חיבור Morning/Grow מאושר לחשבון, חוזה callback ואימות אותנטיות לפי הספק, התאמת סכום/מטבע/הזמנה, idempotency והתאמה מול רשומות הספק. אישור browser אינו מספיק.
- [ ] בדיקת sandbox מאושרת עם כרטיסי הבדיקה הרשמיים בלבד ואישור הספק ל-production. לפי Grow, ארנקים מסוימים עלולים לחייב באמת גם כשזרימה מתחילה ב-sandbox; לא לבדוק אותם ללא אישור מתאים.
- [ ] אישור שהחשבון מאפשר עד שישה תשלומים; עצם קיום שדות API לתשלומים אינו אישור לחשבון העסק.
- [ ] אישור סיווג העסק, מע״מ וסוג המסמך עם רואה החשבון והחשבון אצל הספק.
- [ ] תנאי רכישה, ביטול, החזר, פרטיות ומינימום משתתפים מאושרים וזמינים למשתתף לפני תשלום.
- [ ] שליחת אישור הרשמה, הכנה, קבלות ותזכורות נבדקה עם ספקים מחוברים ומקבלי בדיקה מורשים; outbox מקומי אינו הודעה שנשלחה.
- [ ] מיפוי Fireberry לרישום מאושר ולנתוני הסכמה, מזהים יציבים ומניעת כפילויות. אין לבצע כתיבה ל-CRM ייצור במסגרת בדיקות.
- [ ] עדכון מצב הפרסום ב-llms, הפעלת דגל אינדוקס רק ל-production מאושר ובדיקת noindex לתצוגות מקדימות.

## תוצאות הגרסה המשולבת
בנייה מלאה ו־TypeScript strict עברו. ליבת14 בדיקות המסחר ובדיקת האינדוקס עברו. בדיקות דפדפן ונגישות עברו על33 שילובי עמוד/viewport; מסלול הרשמת סימולציה, הרשאות, קופון, חתימה ומניעת כפל רישום עברו. נבדקה כניסת מנהל מאומתת במאגר בדיקה. בדיקות סופיות וקישורי עוגן מתועדות ב־`docs/academy-qa-report.md`.

Lighthouse מקומי למובייל:83 Performance,100 Accessibility,100 Best Practices. LCP3.2s ו־TBT350ms נותרים יעדים לשיפור/מדידה באירוח אמיתי. אין בסיס השוואה מאומת לאתר החי. נגישות אוטומטית אינה הצהרה משפטית. לא נבדקו Safari/iOS או סליקה אמיתית.

קישור תצוגת build מקומית: `http://localhost:4173/`. פיתוח חי: `http://localhost:5173/`. שני הקישורים אינם פרסום לייצור. האינדוקס חסום.

הרצה סופית: `npm test`34/34 עברו; build ו־git diff --check עברו. נוספה זרימת hosted checkout עם ספק מדומה, lookup מאומת וקישור יחיד להזמנה. נוסף כלי קריאה בטוחה של Morning מ־Keychain על Mac בלבד; הסביבה הנוכחית היא Linux ואין בה גישה למפתחות. לא נוצרו קישורי Morning אמיתיים. מאגר התצוגה הרגיל נשאר ללא שינוי:10 טיוטות,0 הזמנות; הקטלוג נבדק שוב בקריאה בלבד:0 מועדים, סליקה disabled ו-ready=false.
