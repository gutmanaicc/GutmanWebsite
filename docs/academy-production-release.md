## הכנת מעבר מלא ל־Hostinger

הבעלים אישר מעבר מלא מ־Vercel ל־Hostinger. הדומיין נשאר `gutmanai.com`; ה־DNS אומת ומנוהל ב־Namecheap BasicDNS, עם שתי רשומות A (`@` ו־`www`) ל־76.76.21.21, ללא AAAA או CAA. חיבור Hostinger מחזיר אזור DNS ריק לדומיין ואינו שולט ברשומות הסמכותיות האלה. יעד ה־VPS המאומת הוא 76.13.37.15. אין להחליף nameservers או רשומות דואר במסגרת המעבר.

גרסת השרת העצמאית תומכת כעת בייצור מאושר בלי משתנה Vercel: `ACADEMY_DEPLOYMENT_TARGET=hostinger-production` ו־`VITE_ACADEMY_PRODUCTION_APPROVED=1` נדרשים בבנייה, יחד עם דגל המדיה. תהליך Node דורש מקור HTTPS מפורש כש־`ACADEMY_PREVIEW=0`, מפנה www לכתובת הראשית עם הנתיב והשאילתה, ושומר Preview, מסכי רכישה/הזמנה/ביטול ונתיבים שאינם ציבוריים כ־noindex גם בכותרת HTTP וגם ב־HTML. robots מחושב לפי ה־Host. המדידה הקיימת מופעלת רק בדומיין הראשי ולאחר הסכמה.

`compose.production.yml` הוא overlay לאותו שירות ואותם נפחים, עם router ייצור והפעלת דחיסה. בפריסה בפועל יש לשמר את router ה־Preview התקין `gutman-academy-preview-tls2`, middleware הרשמה ואת תמונת המדיה הנעולה. אין לפתוח מופע נוסף על אותו מסד ואין לשנות את Traefik או את שירותי Hermes. HTTPS לדומיין הראשי דורש הנפקת תעודה לאחר חיבור DNS; בדיקת Host לפני המעבר אינה הוכחה לתעודת הדומיין הראשי.

גיבוי עקבי של ארבעת מסדי SQLite ופרופילי הסוחר הפרטיים נשמר ב־`/data/backups/2026-10-13-hostinger-production`, בהרשאות פרטיות ועם quick_check=ok. תצורת האפליקציה הקודמת נשמרה באופן פרטי ב־Composio לצורך חזרה לאחור; אין להחזיר snapshot נתונים מעל הזמנות שנוצרו אחרי הגיבוי. אתר Vercel נשאר זמין כל עוד ה־DNS מצביע אליו, וגם כחלופת חזרה בזמן התפשטות DNS.

בעת הכנת המעבר תוקן גם הבדל של פריים יחיד בהשהיית פס המותגים: עצירת מקלדת מקפיאה את זמן האנימציה מיד, לפני עדכון React. בדיקת ההשהיה והמשך התנועה עברה לאחר התיקון.

## אימות

בדיקה על הדומיין החי מתוך פרויקט Node מבודד ב־VPS הסתיימה exit 0: HTML וחבילה חדשים, שלושת מזהי המדידה, שישה מועדים ו־commerce/CRM ready, מחיר ומקום, quote במקור המאושר, 403 למקור זר, 401 למנהל ללא אימות וקריאת readiness מוגנת עם bearer שעובר דרך ה־proxy. נבדקו עמודים ציבוריים, noindex למסכי הרשמה/הזמנה/ביטול וארכיון, נכסי תמונות וגופן עם MIME תקין, סרטון 206 עם 1,024 בתים, robots/sitemap/llms, הפניית www והפניית הרשמה מ־Preview. לא בוצע חיוב, לא נוצר איש קשר ולא נשלח מייל בבדיקות אלה.

בדיקות הבנייה והמסחר המקומיות עברו. בדיקות דפדפן נעשו על אותה גרסת קוד עם ספקים מדומים; אין טענה להרצת דפדפן חי על האתר או להגעת אירועים לדוחות הספקים. אסימון גישה זמני של Vercel שהופיע בתשובת כלי הבדיקה בוטל. פרויקטי הבנייה, הגיבוי והבדיקה הזמניים הוחלפו בשירותים אינרטיים לפני הסרה; קובצי הגיבוי, מסד הנתונים והמדיה נשמרו.
