מקומות מומלצים: `public/videos/academy-intro.mp4`, `public/images/academy-intro-poster.jpg`, `public/videos/academy-intro.he.vtt`. **העתקת קובץ בלבד אינה חיבור לנגן**: לאחר בדיקת זכויות, תוכן ונגישות יש לחבר את המקורות בתצורה `ACADEMY_CONTENT.introVideo` בתוך `src/data/seminars.ts` (`src`, `poster`, `captionsSrc`) וברכיב הבית ולבדוק טעינה במובייל. עד אז מוצגת הודעה ברורה שהסרטון בהכנה.

## חומרי הכנה שחסרים לאישור הדרכה

- לכל הסמינרים: מחשב נייד ומטען; חיבור Wi‑Fi מאומת במקום; הנחיות התחברות ורשימת חשבונות נדרשים.
- סושיאל: חומרי לקוח מורשים, דוגמאות טון מותג, קהל יעד ומטרת תוכן; להימנע ממידע אישי/סודי ללא הרשאה.
- וידאו: רעיון מצומצם, רפרנסים וחומרי מקור עם זכויות שימוש. לקבוע מראש אילו מנויים/קרדיטים חובה, מה העלות ומה ניתן לבצע בחינם.
- בעלי עסקים: תיאור העסק, שאלות חוזרות ודוגמה לתהליך עבודה; ללא רשימות לקוחות, סיסמאות או נתונים רגישים לתרגול.
- רשימת ״חובה / מומלץ / חלופה חינמית״ לפי סמינר, גרסאות כלים, מגבלות חשבון והאם עלויות צד שלישי כלולות במחיר. אין לחייב רכישת מנוי שלא פורסם מראש.
- חומר המשך והיקף התמיכה לאחר היום: טרם נקבעו. אין לפרסם הבטחת ליווי או תמיכה ללא גבול.

## ניהול עדכונים

ממשק הניהול המקומי אינו CMS למדיה ולתכנים. כותרות, תוכנית ומדיה מנוהלים בנתוני הקטלוג וברכיבי React דרך שינוי נבדק. תמחור מנוהל מרכזית ואינו מופזר במלל. כאשר מצרפים קובץ, יש לוודא גודל, יחס תמונה, פוסטר, טקסט חלופי, כתוביות והסכמת פרסום. יש לבדוק שהתשובה לכתובת קובץ היא המדיה הנכונה, משום ש־SPA עשויה להחזיר HTML לנתיב חסר.
