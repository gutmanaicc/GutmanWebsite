# דוח QA — אקדמיית גוטמן 2.0

בדיקות נעשו מקומית בענף הפיתוח ב־12.10.2026. אין חיוב, פרסום, הודעות חיצוניות או שינוי נתוני ייצור.

## בדיקות אוטומטיות

הרצה סופית: `npm test` — **34/34 עברו**, אפס כישלונות. `npm run build` ו־`git diff --check` עברו לאחר השינויים.

בעקבות בקשת Morning נוספו14 בדיקות: שבע לליבת ספק מוזרק, ארבע לתיאום hosted checkout/HTTP, שתיים לקריאת credentials ממוקדת ואחת לזרימת דפדפן עם ספק מדומה. נבדקים claim שנשמר אחרי restart, קישור יחיד גם בניסיונות מקבילים, כשל עמום ללא יצירה חוזרת, URL ותוקף שאינם מאושרים, אימות lookup/סכום, callback מזויף, חסימת סימולציה במצב ספק, מעבר לדף סליקה וחזרה להזמנה ממתינה, אישור לאחר lookup ורענון ללא הרשמה כפולה. בדיקת Keychain משתמשת ב־executor מדומה; אין גישה ל־Keychain אמיתי מסביבת Linux. כשל ראשון בבדיקת axe החדשה נבע משימוש ב־browser.newPage במקום context מפורש; תוקן מבנה הבדיקה והסבב המלא עבר.

ליבת המסחר כוללת 14 בדיקות: תמחור השקה/רגיל, מס, קופונים וזכאות/מגבלות, מועדים וטיימזון, פקיעת שמירה, תשלום שנכשל, אימות חתימה, כפילויות אירוע/עסקה, רישום, החזר ומניעת מכירת יתר. בדיקות מקביליות נכתבות בפועל ל־SQLite דרך workers נפרדים: 24 בקשות מקבילות מניבות בדיוק 12 שמירות, ו־12 בקשות לקופון שמוגבל לשניים מאפשרות בדיוק שני מימושים. בדיקת אינדוקס מכסה דגלי preview/production, HTML ו־robots.

בדיקות Chromium/Playwright ו־axe מכסות 11 עמודים × 3 גדלים (375,768,1440): בית, קטלוג, שלושה סמינרים, אודות, המלצות, הרשמה חסומה, ארכיון אופנה, סטטוס הזמנה וכניסת מנהל. נבדקים h1 יחיד, Hebrew/RTL, noindex, אפס חריגות JavaScript, היעדר גלילה אופקית ו־WCAG2A/2AA/2.1AA. בדיקת הניהול המאומתת כוללת נגישות וגלילה במובייל; checkout מדמה קופון והזמנה, מוכיח שביקור במסך הזמנה אינו רישום, ואז מאמת הודעה חתומה ומוכיח ש-refresh אינו מכפיל רישום. קישורי עוגן ותוצרי וידאו נבדקים בנפרד.

פקודות: `npm test`, `npm run build` (כולל TypeScript strict), `npm run typecheck`, ובדיקה מבודדת ל־`api/academy.ts`. אין linter מוגדר בריפו; לא נטען שבדיקת lint רצה.

## מדידת ביצועים בפועל

Lighthouse 13.5.0 הורץ על build מקומי ב־`http://127.0.0.1:4173/`, במצב mobile עם ברירות המחדל של CPU/network simulation. המדידה אינה Core Web Vitals של משתמשים בייצור. לא נמדד האתר החי כבסיס השוואה.

| מדד | תוצאה |
| --- | --- |
| Performance | 83 |
| Accessibility | 100 |
| Best Practices | 100 |
| FCP | 2.2 s |
| LCP | 3.2 s |
| TBT | 350 ms |
| CLS | 0.019 |

בגרסת הפיתוח הראשונית נמדד 45 בביצועים. האופטימיזציה איחדה גופנים משתנים (הקבצים במשקלים שונים היו זהים ממש), הקדימה רקע פתיחה, העבירה את האזור שמתחת לפתיחה לטעינה עם תחילת גלילה ובחרה בלוגו המקורי המוקטן (כ־12KB במקום1.3MB). המראה וכל התוכן נשמרים; ניווט עוגן מפעיל גם את האזור המושהה. מדידת הביניים47 הורצה כשגם בדיקות דפדפן אחרות פעלו, ואינה בסיס אמין להשוואת CPU. המדידה הסופית הורצה בנפרד.

LCP3.2s ו־TBT350ms עדיין מצדיקים מעקב ושיפור לפני/אחרי אירוח אמיתי. CSS/JS היסטוריים נשמרים בריפו ובחלק מהחבילה, ואין SSR/prerender מלא. לא בוצעה בדיקת iOS/Safari או מכשיר פיזי; emulation אינו תחליף להן. ציון100 אוטומטי אינו אישור משפטי לנגישות או בדיקה ידנית מלאה עם קורא מסך.

תוצרי הבדיקה המקומיים: `artifacts/browser-verification.json`, `artifacts/lighthouse-mobile-release.json`, `artifacts/academy-owner-preview-1440.png`, `artifacts/academy-owner-preview-375.png`. artifacts אינו נשלח לייצור ונמצא ב־gitignore.

## גבולות הבדיקה

Morning/Grow לא נבדק מול חשבון סוחר, ומערכת קבלות, דיוור ו־CRM אינה מחוברת לזרימה החדשה. outbox מאומת מקומית עם adapter בדיקה בלבד; הוא אינו הוכחת מסירה. תנאי ביטול, מס, עלויות כלים ומקום דורשים אישור. עשרת המועדים במאגר התצוגה הרגיל הם טיוטות; אישורים בבדיקות מתרחשים במאגר memory נפרד ואינם משנים אותם.

בדיקת CLI נוספת מפעילה בפועל את סקריפט השרת במאגר memory נפרד, בודקת את הקטלוג ואת כניסת המנהל ומוכיחה שברירת המחדל היא סליקה חסומה ומועדים שלא פורסמו.
תמונות העמוד המלא מציגות קומפוזיציה סטטית של כל הכרטיסים: sticky הושבת בדפדפן הצילום בלבד, כדי למנוע חפיפת כרטיסים בצילום של מסמך שלם. מנגנון הגלילה והערימה באתר נשאר פעיל.
